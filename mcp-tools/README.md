# MCP (Model Context Protocol) 模块说明

该模块实现了标准的MCP工具协议，为AI旅行助手提供实时数据和上下文增强功能。

## 目录结构

```
mcp-tools/
├── index.js          # 模块入口和标准输出
├── tools.js          # MCP工具定义（接口规范）
├── implementations.js # 工具实现（真实API调用或模拟）
└── dispatcher.js     # MCP路由/调度器
```

## 功能特性

- **标准化协议**：使用标准的MCP格式定义工具
- **模块化解构**：分离工具定义、实现和调度逻辑
- **实时数据增强**：提供天气、POI详情、路线路线等功能
- **错误处理**：包含真实的API调用和备用模拟实现
- **兼容性设计**：向后兼容原有AI工具调用流程

## 使用方式

服务器现在通过MCP标准与AI模型交互，当AI返回location工具调用后，系统会在后台调用MCP工具来获取实时数据（天气、交通、POI详情等）并丰富行程规划结果。
