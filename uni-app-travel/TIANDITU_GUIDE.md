## 核心代码说明

### 地图组件配置

```vue
<map 
  id="tianditu-map"
  class="map-container"
  :longitude="mapCenter[1]"      // 经度
  :latitude="mapCenter[0]"       // 纬度
  :scale="mapZoom"               // 缩放级别
  :show-location="true"          // 显示当前位置
  :enable-zoom="true"            // 启用缩放
  :enable-scroll="true"          // 启用滚动
>
  <!-- 标注点 -->
  <marker
    v-for="marker in markers"
    :latitude="marker.latitude"
    :longitude="marker.longitude"
    :callout="marker.callout"
    :label="marker.label"
  />
</map>
```

### 标注点数据结构

```javascript
{
  id: 0,                         // 唯一ID
  latitude: 34.3416,             // 纬度
  longitude: 108.9398,           // 经度
  title: "大雁塔",               // 标题
  callout: {                     // 点击气泡
    content: "Day 1 - 大雁塔",
    display: "BYCLICK",          // 点击显示
    bgColor: "#FF6B6B",          // 背景色（按天数）
    padding: 10,
    borderRadius: 5,
    fontSize: 12
  },
  label: {                       // 常驻标签
    content: "Day 1",
    color: "#FF6B6B",
    fontSize: 12,
    bgColor: "#FFFFFF",
    anchorY: -20                 // 偏移量
  }
}
```

### 天数颜色方案

## 与原Web端对比

| 功能 | Web端 (Leaflet) | 微信小程序 (Map组件) |
|------|-----------------|---------------------|
| 地图引擎 | Leaflet + 天地图WMTS | 腾讯地图 |
| 天地图瓦片 | ✅ 直接加载 | ❌ 不能直接加载 |
| 标注点 | ✅ Marker | ✅ Marker |
| 路线绘制 | ✅ Polyline | ✅ Polyline |
| 区域标注 | ✅ Polygon | ✅ Polygon |
| 自定义图标 | ✅ 完全支持 | ✅ 支持 |
| 气泡提示 | ✅ Popup | ✅ Callout |

### 差异说明

**重要**: 微信小程序的`<map>`组件使用腾讯地图作为底层，不能完全替换为天地图瓦片。但是：

1. ✅ **标注功能完全支持** - 可以正常标注行程点
2. ✅ **交互功能完善** - 缩放、滚动、点击等都支持
3. ⚠️ **地图底图不同** - 使用腾讯地图而非天地图
4. 💡 **可以获取天地图数据** - 通过天地图API获取POI等数据

## 如果需要使用天地图瓦片

### 方案1: 使用第三方SDK

使用支持天地图的第三方微信小程序SDK：
```bash
npm install @tianditu/weixin-sdk
```

### 方案2: 使用WebView嵌入

在小程序中嵌入WebView加载天地图网页版：
```vue
<web-view src="https://map.tianditu.com/..."></web-view>
```

### 方案3: 继续使用腾讯地图（推荐）

- 腾讯地图数据也很完善
- 与微信小程序兼容性最好
- 性能更优
- 无需额外配置

## 常见问题

### Q1: 为什么不直接使用天地图？
**A**: 微信小程序的`<map>`组件底层使用腾讯地图，不能完全替换为天地图瓦片。但标注、交互等功能都可以正常使用。

### Q2: 能否在小程序中使用天地图API？
**A**: 可以！可以使用天地图的API获取POI数据、地理编码等，只是底图显示使用腾讯地图。

### Q3: 标注点不显示怎么办？
**A**: 
1. 检查行程数据是否包含经纬度（lat/lng）
2. 查看Console是否有错误信息
3. 确认markers数组已正确赋值

### Q4: 地图加载慢怎么办？
**A**:
1. 检查网络连接
2. 减少标注点数量
3. 使用标注聚类
4. 在真机上测试（模拟器性能较差）
