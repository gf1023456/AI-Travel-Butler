# 静态资源说明

## 需要的图标文件

### 1. 用户头像
**文件**: `/static/avatar.png`
- 尺寸: 70x70px
- 格式: PNG（支持透明背景）
- 用途: 顶部导航栏用户头像

### 2. 地图标注图标
**文件**: `/static/marker.png`
- 尺寸: 30x30px
- 格式: PNG（支持透明背景）
- 用途: 地图行程标注点

### 3. 不同天数的标注图标（可选）
```
/static/
  ├── marker-day1.png    # Day 1 - 红色
  ├── marker-day2.png    # Day 2 - 青色
  ├── marker-day3.png    # Day 3 - 蓝色
  ├── marker-day4.png    # Day 4 - 橙色
  └── marker-day5.png    # Day 5 - 绿色
```

## 临时解决方案

如果暂时没有图标文件，可以：

1. **使用emoji替代**
   - 代码中已经使用emoji作为临时图标

2. **在线生成图标**
   - 使用 https://www.iconfont.cn/
   - 使用 https://iconify.design/

3. **使用默认图标**
   - 微信小程序提供默认图标
   - 暂时不设置iconPath属性

## 推荐图标尺寸

| 用途 | 宽度 | 高度 | 格式 |
|------|------|------|------|
| 用户头像 | 70px | 70px | PNG |
| 地图标注 | 30px | 30px | PNG |
| 导航图标 | 44px | 44px | PNG/SVG |
| 按钮图标 | 32px | 32px | PNG/SVG |

## 图标设计规范

### 颜色方案
- **主色调**: #667eea (紫色渐变)
- **辅助色**: #764ba2 (紫色渐变)
- **成功色**: #4CAF50 (绿色)
- **警告色**: #f57c00 (橙色)
- **错误色**: #f44336 (红色)

### 风格
- 扁平化设计
- 圆角处理
- 半透明效果（地图覆盖物）
