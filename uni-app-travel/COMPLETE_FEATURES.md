## 🔧 技术实现

### 卫星地图切换（核心修复）

**原问题**: 切换卫星没反应

**解决方案**: 使用微信小程序`<map>`组件的`enable-satellite`属性

```vue
<map 
  :enable-satellite="isSatellite"
  ...
/>
```

**切换逻辑**:
```javascript
const toggleMapType = () => {
  isSatellite.value = !isSatellite.value
  showToast(isSatellite.value ? '已切换到卫星地图' : '已切换到普通地图', 'normal', 1500)
}
```

### 路线绘制

使用微信小程序`<map>`的`polyline`属性：

```javascript
polylines.value = [
  {
    points: [{latitude, longitude}, ...],
    color: '#FF6B6B',
    width: 5,
    dottedLine: false,
    arrowLine: false,
    borderColor: '#FFFFFF',
    borderWidth: 2
  }
]
```

### 地图标注

```javascript
markers.value = [
  {
    id: 0,
```

## 🚀 使用流程

### 1. 生成行程
1. 点击顶部搜索栏或"探索"按钮
2. 输入旅行需求（如"北京三日游"）
3. 选择生成模式（景点发现/行程规划）
4. 选择旅行风格
5. 点击"开始规划"
6. 等待AI生成
7. 自动打开行程面板

### 2. 查看地图标注
1. 生成行程后自动标注
2. 点击行程卡片飞到标注点
3. 点击标注点查看详情
4. 查看每天的路线图

### 3. 切换地图类型
1. 点击底部"卫星"导航
2. 在普通地图和卫星地图间切换
3. 显示切换提示

### 4. 保存行程
1. 打开行程面板
2. 点击"💾"保存按钮
3. 行程保存到本地历史

### 5. 查看历史
1. 点击底部"历史"导航
2. 查看历史列表
3. 点击加载历史行程
4. 可删除不需要的记录

### 6. 复制/导出
1. 打开行程面板
2. 点击"📋"复制按钮
3. 行程复制到剪贴板
4. 点击"📥"导出按钮
5. 分享行程

## 📝 注意事项

### 地图相关
1. **地图服务**: 使用腾讯地图（微信小程序限制）
2. **卫星地图**: 使用`enable-satellite`属性切换
3. **标注数量**: 建议不超过50个
4. **路线数量**: 按天数分别绘制

### 存储相关
1. **历史记录**: 最多30条
2. **存储大小**: 注意uni Storage容量限制
3. **防重复**: 相同内容不重复保存

### 性能优化
1. **懒加载**: 面板按需显示
2. **计算属性**: 使用computed优化排序
3. **响应式**: 使用ref管理状态
