# 更新日志 - 修复API参数和首页设计

## 更新内容

### 1. 修复 400 Bad Request 错误

**问题原因**:
- 后端API期望的参数是 `userInput`（字符串）和 `modelType`（字符串）
- 之前发送的是 `{destination, duration, budget, interests}` 格式，导致后端验证失败

**后端API期望格式**:
```javascript
{
  userInput: "北京三日游",        // 必需 - 用户输入的旅行需求
  modelType: "auto",              // 必需 - AI模型类型
  isPlannerMode: false,           // 可选 - 是否为行程规划模式
  travelMode: "deep"              // 可选 - 旅行风格
}
```

**修复文件**:
- ✅ `src/store/travel.js` - 更新createPlan和refinePlan方法的参数
- ✅ `src/api/travel.js` - 更新API接口的参数格式
- ✅ `src/pages/index/index.vue` - 使用正确的参数调用
- ✅ `src/pages/refine/refine.vue` - 优化页面参数调整

## 参数说明

### 创建行程参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| userInput | String | ✅ | 用户输入，如"北京三日游" |
| modelType | String | ✅ | AI模型：auto/gemini-2.5-flash/deepseek-chat/glm-4-flash/qwen-plus |
| isPlannerMode | Boolean | ❌ | 是否行程规划模式，默认false |
| travelMode | String | ❌ | 旅行风格：deep/special/relax/photo，默认deep |

### 优化行程参数

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| userInput | String | ✅ | 基础用户输入 |
| modelType | String | ✅ | AI模型类型 |
| isPlannerMode | Boolean | ✅ | 规划模式 |
| travelMode | String | ✅ | 旅行风格 |
| refineInstruction | String | ✅ | 优化指令 |
| basePlan | Object | ❌ | 基础行程对象 |
