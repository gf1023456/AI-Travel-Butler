# 地图标注优化说明

## ✅ 问题修复

### 问题描述
生成行程后，地图上只显示路线，标注点没有显示景点名称和详细信息。

### Web端效果
Web端使用Leaflet的 `bindPopup` 功能，点击标注点会弹出包含以下信息的Popup：
- 景点名称（带天数颜色）
- 天数、时间、城市
- 景点描述

### 小程序端修复方案

由于微信小程序`<map>`组件的限制，我们采用了双重显示策略：

#### 1. **始终显示名称标签**
- 使用 `callout` 属性，设置 `display: 'ALWAYS'`
- 每个标注点始终显示彩色圆形背景的名称标签
- 颜色按天数区分（10种颜色循环）

```javascript
callout: {
  content: item.name,           // 景点名称
  display: 'ALWAYS',            // 始终显示
  padding: 8,
  borderRadius: 20,             // 圆形背景
  fontSize: 13,
  bgColor: dayColor,            // 天数颜色
  color: '#FFFFFF',
  textAlign: 'center',
  boxShadow: '0 2px 8px rgba(0,0,0,0.2)'
}
```

#### 2. **天数标签**
- 使用 `label` 属性显示天数
- 显示在标注点上方（anchorY: -30）
- 白色背景，彩色文字

```javascript
label: {
  content: `D${item.day}`,      // 如 "D1", "D2"
  color: dayColor,
  fontSize: 11,
  fontWeight: 'bold',
  borderRadius: 10,
  padding: 3,
  bgColor: '#FFFFFF',
  anchorX: 0,
  anchorY: -30                  // 显示在上方
}
```

#### 3. **点击显示详情弹窗**
点击标注点后弹出详细信息弹窗，包含：
- 📅 游玩时间
- 🌤️ 天气信息（如有）
- 📖 景点介绍
- 🚗 交通提示
- ⏱️ 建议游玩时长

## 🔧 技术实现

### 数据结构

```javascript
marker = {
  id: 0,                      // 标注点ID
  latitude: 34.3416,          // 纬度
  longitude: 108.9398,        // 经度
  title: "大雁塔",            // 标题
  callout: {                  // 名称标签
    content: "大雁塔",
    display: "ALWAYS",
    bgColor: "#FF6B6B",
    ...
  },
  label: {                    // 天数标签
    content: "D1",
    color: "#FF6B6B",
    anchorY: -30,
    ...
  },
  detail: {                   // 完整信息（用于弹窗）
    id: 0,
    name: "大雁塔",
    day: 1,
    dayColor: "#FF6B6B",
    time: "上午 8:00-10:00",
    city: "西安",
    description: "...",
    transit_hint: "...",
    visit_duration: "...",
    weather_icon: "☀️",
    temperature: "22°C",
    lat: 34.3416,
    lng: 108.9398
  }
}
```

### 点击事件处理

```javascript
const onMarkerTap = (e) => {
  const markerId = e.markerId
  const marker = markers.value.find(m => m.id === markerId)
  
  if (marker && marker.detail) {
    // 显示详情弹窗
    selectedMarker.value = marker.detail
    showMarkerDetail.value = true
    
    // 地图移动到该标注点
    mapCenter.value = [marker.latitude, marker.longitude]
    mapZoom.value = 15
  }
}
```

## 💡 与Web端差异说明

### 为什么不用Popup？

微信小程序`<map>`组件的`callout`功能有限：
1. ❌ 不支持富文本HTML
2. ❌ 不支持自定义布局
3. ❌ 只能显示纯文本

### 我们的解决方案

1. **名称始终显示** - 使用callout的ALWAYS模式
2. **详细信息** - 使用自定义弹窗（Modal）
3. **更好的体验** - 点击后自动放大地图

### 优势对比

| 特性 | Web端Popup | 小程序弹窗 |
|------|-----------|-----------|
| 名称可见性 | 点击才显示 | **始终显示** ✅ |
| 信息丰富度 | 受限于Popup | **完整详情** ✅ |
| 交互体验 | 原地显示 | **移动+放大** ✅ |
| 自定义样式 | CSS控制 | **完全自定义** ✅ |
